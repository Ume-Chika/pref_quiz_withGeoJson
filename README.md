# 都道府県ミニゲーム

都道府県の形や位置を、短いミニゲームで繰り返し覚える日本語の学習アプリです。学習履歴をもとに、未学習・復習時期・苦手分野を考慮して次の問題を選びます。

**公開ページ:** https://ume-chika.github.io/pref_quiz_withGeoJson/

## 特徴

- 10問モードとエンドレスモード
- 初見の形・位置を短い見本で教え、3問後にヒントなしで確かめる導入
- 逆シルエット、地図と形の相互問題、形から地方、郷土料理から形、地図フラッシュ、全国地図タップ、方角などを含む30種類の出題
- 15秒タイマー、スコア、コンボ、ハイスコア
- 都道府県・分野ごとの学習履歴と間隔反復
- 直近10問の正誤を色分けし、県の詳細を調べられる白地図
- 正解県の形を再確認し、県名の誤答時は2県の形を比較できる正誤画面
- 10問あたり新規項目を最大4件に抑え、既習項目を繰り返す段階学習
- スマートフォン優先の軽量なHTML・CSS・Vanilla JavaScript
- 登録、広告、アクセス解析、外部AI、専用バックエンドなし

学習履歴・設定・ハイスコアはブラウザ内にだけ保存されます。別の端末やブラウザとは同期されず、ブラウザデータを削除すると失われます。

## 遊び方

1. 「10問」または「エンドレス」を選んで開始します。
2. 15秒以内に選択肢または地図から回答します。
3. 正誤と短い補足を確認し、次の問題へ進みます。
4. 10問モードでは終了後に成績と次の復習候補を確認できます。

ホームの「白地図を眺める」では、直近10問の正解県を緑、不正解・時間切れの県を赤で確認できます。県にホバーまたはタップすると、県名・地方・県庁所在地・郷土料理と直近の結果を表示します。同じ県が複数回ある場合は最新の回答を地図色に使います。

回答方法、効果音・音量、学習データの消去は設定から変更できます。効果音の初期値はOFFです。

## キーボード

- `1`〜`4`: 選択肢を選ぶ
- `Enter`: 回答を決定／次へ進む
- 白地図では `矢印`: 県を移動、`Enter`: 詳細を表示
- `Esc`: 開いている設定画面を閉じる

画面に表示される案内が上記より優先されます。

## ローカルで実行

ビルドや依存ライブラリのインストールは不要です。リポジトリのルートで次を実行し、<http://localhost:8000> を開きます。

```sh
python3 -m http.server 8000
```

`index.html` を直接開くと、ブラウザの制限によりデータを読み込めない場合があります。

## 構成

```text
index.html          画面
static/css/         スタイル
static/js/          ゲームと学習ロジック
static/data/        公開用の問題・地理データ
.github/workflows/  検査とGitHub Pages公開
```

## 開発と公開

`main` は公開可能な状態に保ち、変更は `codex/` で始まるブランチからPull Requestにします。GitHub ActionsはJavaScript構文、ローカル参照、GeoJSON、Chrome操作、LighthouseモバイルPerformance 90以上を検査し、`main` の成功時にGitHub Pagesへ公開します。LighthouseレポートはActionsの成果物から確認できます。

ローカルでも同じ主要検査を実行できます。

```sh
node .github/validate.mjs
CHROME_BIN="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node .github/chrome-smoke.mjs
```

2行目はmacOS版Chromeの例です。ほかの環境では `CHROME_BIN` にChrome実行ファイルを指定してください。

GitHubリポジトリの **Settings → Pages → Build and deployment → Source** は **GitHub Actions** を選択してください。
