# 都道府県ミニゲーム

都道府県の形や位置を、短いミニゲームで繰り返し覚える日本語の学習アプリです。学習履歴をもとに、未学習・復習時期・苦手分野を考慮して次の問題を選びます。

**公開ページ:** https://ume-chika.github.io/pref_quiz_withGeoJson/

## 特徴

- おすすめ学習10問、実力テスト30問、エンドレス学習
- 初見の形は県名と輪郭の見本後に4つの形から答え、3問後にヒントなしで確かめる導入
- 逆シルエット、隙間を流れる県、地方の形、地図と形の相互問題、郷土料理から形、全国地図タップ、方角などを含む32種類の出題
- 都道府県理解度指数、正解数、連続正解、実力テストの直近3回平均
- 都道府県・分野ごとの学習履歴と間隔反復
- 実際に取り違えた県を次回の誤答候補へ1件だけ再提示する混同対策
- 現在の得意・苦手を任意に色分けし、直近10問の履歴と県の詳細を調べられる白地図
- 正解県を同じ拡大率の周辺地図で再確認し、県名の誤答時は2県の形と場所を比較できる正誤画面
- 10問あたり新規項目を最大4件に抑え、既習項目を繰り返す段階学習
- スマートフォン優先の軽量なHTML・CSS・Vanilla JavaScript
- 登録、広告、アクセス解析、外部AI、専用バックエンドなし

学習履歴・設定・直近3回の実力テスト結果はブラウザ内にだけ保存されます。別の端末やブラウザとは同期されず、ブラウザデータを削除すると失われます。

## 遊び方

1. 「おすすめ学習 10問」「実力テスト 30問」「エンドレス学習」から開始します。
2. 15秒以内に選択肢または地図から回答します。
3. 正誤と短い補足を確認し、次の問題へ進みます。
4. 通常学習では理解度指数と次の復習候補、実力テストでは最後にまとめて実力スコアを確認できます。

ホームの「白地図を眺める」では、学習記録から判定した得意な県を緑、復習がおすすめの県を赤で表示できます。2色はそれぞれチェックボックスで隠せます。県にホバーまたはタップすると、県名・地方・県庁所在地・郷土料理と直近10問内の結果を表示します。地図はスライダーまたはボタンで100〜250%まで25%刻みで拡大でき、いつでも元の倍率に戻せます。

都道府県理解度指数は、全47県の形・位置を重く、県庁所在地・地方区分・郷土料理も含めて0〜1000で表します。実力テストはA〜Eを各6問、重複しない30県から出題し、4択の偶然正解分を補正した別スコアです。途中の答え合わせはなく、受験しても通常の習熟度や復習予定は変わりません。

回答方法、視覚効果、効果音・音量、学習データの消去は設定から変更できます。視覚効果は初期値ONで、OFFでは光・動きのある問題形式を出しません。効果音は初期値OFFです。

## キーボード

- `1`〜`4`: 選択肢を選ぶ
- `Enter`: 回答を決定／次へ進む
- 白地図では `矢印`: 県を移動、`Enter`: 詳細を表示
- `Esc`: 開いている設定画面を閉じる

画面に表示される案内が上記より優先されます。

## ローカルで実行

ビルドや依存ライブラリのインストールは不要です。リポジトリのルートで次を実行し、<http://localhost:8000> を開きます。

```sh
python3 -m http.server 8000
```

`index.html` を直接開くと、ブラウザの制限によりデータを読み込めない場合があります。

## 構成

```text
index.html          画面
static/css/         スタイル
static/js/          ゲームと学習ロジック
static/data/        公開用の問題・地理データ
.github/workflows/  検査とGitHub Pages公開
```

## 開発と公開

`main` は公開可能な状態に保ち、変更は直接コミットします。GitHub ActionsはJavaScript構文、ローカル参照、GeoJSON、Chrome操作、LighthouseモバイルPerformance 90以上・Accessibility 95以上を検査し、`main` の成功時にGitHub Pagesへ公開します。LighthouseレポートはActionsの成果物から確認できます。

ローカルでもNode.js 22以上で同じ主要検査を実行できます。

```sh
node .github/validate.mjs
CHROME_BIN="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" node .github/chrome-smoke.mjs
```

2行目はmacOS版Chromeの例です。ほかの環境では `CHROME_BIN` にChrome実行ファイルを指定してください。

GitHubリポジトリの **Settings → Pages → Build and deployment → Source** は **GitHub Actions** を選択してください。
